# Nopalpante — prototype ulang tahun

Prototype Next.js mobile-first untuk alur hadiah ulang tahun Nopalpante dari Putriimut.

## Menjalankan

```bash
npm install
npm run dev
```

Buka alamat lokal yang ditampilkan Next.js. PIN demo: `1234`.

## Pemeriksaan

```bash
npm run test:e2e
npm run build
```

Tes browser membutuhkan Google Chrome terpasang. Data personal yang belum diberikan sengaja ditampilkan sebagai slot foto dan teks demo yang mudah diganti di `app/data.ts` serta komponen surat di `app/page.tsx`.
